# First Commit Hackathon — Top 3 Idea Plans

> WeMakeDevs × AWS · Sept 17–20, 2026 · Founder: Kunal Kushwaha

These are the top 3 project ideas, selected by scoring the full brainstormed field
against the actual First Commit rubric and the organizer's stated intent.

## How they were chosen

**The rubric (5 criteria):** Idea & Impact · Built on AWS · Learning · Execution · Demo Video.
**Organizer intent (verbatim):** *"A small problem solved well beats a big one solved vaguely"*
and *"One feature that runs beats five that almost do."*
**AWS's 2026 push:** agentic AI — Bedrock, AgentCore, Strands Agents SDK (multi-tool agents).
**Kunal's ethos:** open source, lowering barriers for early-career devs, "contributions not clicks."

**The one law all analysis converged on:** the LLM must *narrate a deterministic pipeline*,
never be required to be correct on arbitrary live input on camera. Ideas that violate this
(fabricated citations, live-audio, arbitrary-repo code-gen, unverifiable risk scores) are traps.
